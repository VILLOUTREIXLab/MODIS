Utilities (modis.utils)¶

The modis.utils package provides I/O helpers, evaluation functions, configuration management, display utilities, and model-selection tools.

I/O (modis.utils.io)¶

I/O utilities for MODIS.

This module provides helpers for loading checkpoints, training logs, and configuration files from disk.

load_config(config_file)[source]¶

Load and validate a MODIS configuration from a YAML file.

Parameters:

config_file (str or pathlib.Path) – Path to the YAML configuration file.

Returns:

The loaded and validated configuration object.

Return type:

omegaconf.DictConfig

Raises:

SystemExit – If the configuration fails validation (see validate_config()).

load_checkpoint(checkpoint_file)[source]¶

Load a model checkpoint from disk.

Parameters:

checkpoint_file (pathlib.Path) – Path to the .pth checkpoint file.

Returns:

Checkpoint dictionary containing at least 'model_state', 'optimizer_state', 'epoch', 'best_epoch', 'best_loss', 'val_acc', and 'timestamp'.

Return type:

dict

Raises:

FileNotFoundError – If checkpoint_file does not exist.

load_log(checkpoint_file)[source]¶

Load a training log from a JSON file.

Parameters:

checkpoint_file (pathlib.Path) – Path to the JSON log file.

Returns:

List of per-epoch metric dictionaries, in chronological order.

Return type:

list[dict]

Raises:

FileNotFoundError – If checkpoint_file does not exist.

Configuration (modis.utils.config)¶

Configuration utilities for MODIS.

This module provides helpers for loading, validating, and manipulating OmegaConf configuration objects used throughout the MODIS pipeline.

validate_config(config)[source]¶

Validate a MODIS training configuration.

Checks for the presence of all required fields, validates data types and value ranges, and verifies consistency between settings (e.g., num_classes is required in supervised mode). Exits the program with an error message if any validation rule is violated.

The following fields are required:

dataset_name, model_name, latent_size, modalities, training_mode, batch_size, num_epochs, learning_rate, beta, beta1, lambda_r, device, save_checkpoint_latest, save_checkpoint_best.

Parameters:

config (omegaconf.DictConfig) – The configuration object to validate.

Raises:

SystemExit – If any validation rule is not satisfied.

Return type:

None

config_from_dict(config_dict)[source]¶

Create a validated configuration from a plain Python dictionary.

Parameters:

config_dict (dict) – Dictionary to convert into an OmegaConf DictConfig.

Returns:

A validated configuration object.

Return type:

omegaconf.DictConfig

Raises:

SystemExit – If the dictionary fails validation (see validate_config()).

set_param(config, param_name, param_value)[source]¶

Set a parameter value inside an OmegaConf configuration object.

Supports both top-level keys and nested keys expressed in dot notation (e.g., 'modalities.0.input_size').

Parameters:

  • config (omegaconf.DictConfig) – The configuration object to modify.

  • param_name (str) – Name of the parameter to update. May be a simple key or a dot-separated nested key.

  • param_value – The new value for the parameter.

Raises:

KeyError – If param_name does not exist in the configuration.

Return type:

None

generate_grid(base_config_file, params)[source]¶

Generate a grid of configurations from a base config and parameter ranges.

Loads a base configuration file and returns one omegaconf.DictConfig per unique combination of the supplied parameter values. Each configuration is validated before being added to the grid.

Parameters:

  • base_config_file (pathlib.Path) – Path to the base YAML configuration file.

  • params (dict) – Dictionary of parameters to vary. Keys are parameter names (simple or dot-notation nested), values are lists of possible values (e.g., {'latent_size': [32, 64], 'beta': [1e-4, 1e-3]}).

Returns:

One validated configuration object per parameter combination.

Return type:

list[omegaconf.DictConfig]

Raises:

  • FileNotFoundError – If base_config_file does not exist.

  • ValueError – If params is empty or the base configuration fails to load.

flatten_omegaconf(config, parent_key='')[source]¶

Flatten a nested OmegaConf object into a single-level dictionary.

Nested keys are represented using dot notation (e.g., 'parent.child.key').

Parameters:

  • config (omegaconf.DictConfig or omegaconf.ListConfig) – The OmegaConf object to flatten.

  • parent_key (str) – Base key prefix for the current recursion level. Defaults to ''.

Returns:

A flat dictionary mapping dot-notation key strings to their values.

Return type:

dict

Evaluation (modis.utils.evaluation)¶

Evaluation utilities for MODIS.

This module provides functions for computing classification metrics, evaluating trained models on datasets, and running batch checkpoint evaluations.

accuracy(logits, target)[source]¶

Compute top-1 accuracy from logits and ground-truth labels.

Parameters:

  • logits (torch.Tensor) – Raw model output of shape (batch_size, n_classes).

  • target (torch.Tensor) – Ground-truth label indices of shape (batch_size,).

Returns:

Fraction of correctly predicted samples in [0, 1].

Return type:

float

calc_classification_metrics(true_labels, pred_labels)[source]¶

Compute a suite of classification metrics.

Parameters:

  • true_labels (array-like) – Ground-truth label array of shape (n_samples,).

  • pred_labels (array-like) – Predicted label array of shape (n_samples,).

Returns:

Dictionary with the following keys:

  • 'acc' (float): Overall accuracy.

  • 'bacc' (float): Balanced accuracy (macro-averaged recall).

  • 'nmi' (float): Normalized Mutual Information.

  • 'ji' (float): Macro-averaged Jaccard Index.

  • 'ari' (float): Adjusted Rand Index.

  • 'f1' (float): Weighted-average F1-score.

Return type:

dict

evaluate_model(model, dataloaders)[source]¶

Evaluate a trained model on labeled samples from multiple dataloaders.

Iterates through the dataloaders, computes predictions and reconstruction losses for all labeled samples, and aggregates results across modalities. Samples with label -1 are treated as unlabeled and skipped.

Parameters:

  • model – The trained Model to evaluate.

  • dataloaders (list[torch.utils.data.DataLoader]) – One DataLoader per modality.

Returns:

Evaluation metric dictionary. Returns an empty dict if no labeled samples are found. Otherwise contains all keys from calc_classification_metrics() plus:

  • 'mse' (float): Mean reconstruction MSE across all modalities.

  • 'modal_mse' (list[float]): Per-modality mean reconstruction MSE.

Return type:

dict

evaluate_checkpoint(config, checkpoint_dir, checkpoint_opt, train_dataloaders, val_dataloaders, metrics_data)[source]¶

Evaluate a model loaded from a specific checkpoint.

Loads the model weights from the given checkpoint, runs evaluation on both training and (optionally) validation data, prints results to stdout, and stores them in metrics_data.

Parameters:

  • config (omegaconf.DictConfig) – Model configuration.

  • checkpoint_dir (pathlib.Path) – Directory containing the checkpoint file.

  • checkpoint_opt (str) – Checkpoint variant to load; either 'best' or 'latest'.

  • train_dataloaders (list[torch.utils.data.DataLoader]) – Training data loaders.

  • val_dataloaders (list[torch.utils.data.DataLoader] or None) – Validation data loaders, or None if no validation set is available.

  • metrics_data (dict) – Dictionary in which evaluation results are stored under metrics_data[checkpoint_opt]['train'] and metrics_data[checkpoint_opt]['validation'].

Return type:

None

launch_checkpoints_evaluation(train_datasets, val_datasets, checkpoint_dir)[source]¶

Evaluate the best and/or latest checkpoints and save results to JSON.

Loads the run’s configuration, then—based on save_checkpoint_latest and save_checkpoint_best flags—calls evaluate_checkpoint() for each enabled checkpoint. Results are written to checkpoints_evaluation_metrics.json inside checkpoint_dir.

Parameters:

  • train_datasets (list[torch.utils.data.Dataset]) – Training datasets, one per modality.

  • val_datasets (list[torch.utils.data.Dataset] or None) – Validation datasets, one per modality, or None.

  • checkpoint_dir (pathlib.Path) – Directory where checkpoint files and the configuration YAML are stored.

Return type:

None

avg_mse_all_pairs(X, X_hat)[source]¶

Compute the average MSE between all pairs of vectors from two tensors.

Uses broadcasting to efficiently calculate the mean squared error between every vector in X and every vector in X_hat.

Parameters:

  • X (torch.Tensor) – First tensor of shape (n, d).

  • X_hat (torch.Tensor) – Second tensor of shape (m, d).

Returns:

Average MSE across all n × m pairs.

Return type:

float

Display (modis.utils.display)¶

Display utilities for MODIS.

This module provides small helpers for formatting output in the console.

adjust_time(seconds)[source]¶

Convert a duration in seconds to a human-readable string.

Automatically selects the most convenient unit — nanoseconds, microseconds, milliseconds, seconds, minutes, hours, or days.

Parameters:

seconds (float) – Duration in seconds.

Returns:

Human-readable duration string with the unit appended (e.g., '2.34 minutes', '150.00 ms').

Return type:

str

Examples

>>> adjust_time(0.0000004)
'400.00 ns'
>>> adjust_time(3661)
'1.02 hours'

Model Selection (modis.utils.model_selection)¶

Model selection utilities for MODIS.

This module provides helpers for flattening configurations, validating them, setting individual parameters, and generating hyperparameter grids for model selection experiments.

generate_grid(base_config_file, params)[source]¶

Generate a hyperparameter grid from a base configuration file.

Loads a base YAML configuration and returns one validated omegaconf.DictConfig per unique combination of the supplied parameter values.

Parameters:

  • base_config_file (pathlib.Path) – Path to the base YAML configuration file.

  • params (dict) – Hyperparameters to vary. Keys are parameter names (simple or dot-notation nested) and values are lists of candidate values (e.g., {'latent_size': [32, 64], 'beta': [1e-4, 1e-3]}).

Returns:

One validated configuration per parameter combination.

Return type:

list[omegaconf.DictConfig]

Raises:

  • FileNotFoundError – If base_config_file does not exist.

  • ValueError – If params is empty or the base configuration fails to load.

  • KeyError – If any parameter name does not exist in the base configuration.

flatten_omegaconf(config, parent_key='')[source]¶

Flatten a nested OmegaConf object into a single-level dictionary.

Nested keys are represented using dot notation (e.g., 'parent.child.key').

Parameters:

  • config (omegaconf.DictConfig or omegaconf.ListConfig) – The OmegaConf object to flatten.

  • parent_key (str) – Base key prefix for the current recursion level. Defaults to ''.

Returns:

Flat dictionary mapping dot-notation strings to their values.

Return type:

dict

validate_config(config)[source]¶

Validate a MODIS training configuration.

Checks for required fields, value ranges, type constraints, and cross-field consistency. Exits the program with an informative message if any rule is violated.

Parameters:

config (omegaconf.DictConfig) – Configuration object to validate.

Raises:

  • SystemExit – If the configuration is invalid.

  • TypeError – If beta is neither a float nor a list.

  • AssertionError – If beta is a list whose length does not match the number of modalities.

Return type:

None

set_param(config, param_name, param_value)[source]¶

Set a parameter value inside an OmegaConf configuration object.

Supports both top-level keys and nested keys in dot notation (e.g., 'modalities.0.input_size').

Parameters:

  • config (omegaconf.DictConfig) – Configuration object to modify.

  • param_name (str) – Name of the parameter to update.

  • param_value – The new value.

Raises:

KeyError – If param_name does not exist in the configuration.

Return type:

None
